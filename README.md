# Cooking Recipe

Página web sencilla y estructurada para presentar la receta paso a paso de galletas con chispas de chocolate utilizando **HTML5** semántico.

---

## 🚀 Características

- **Estructura Semántica:** Uso del contenedor principal `<main>` y encabezados jerárquicos (`<h1>`, `<h2>`).
- **Listas Formateadas:** Utilización de listas desordenadas (`<ul>`) para clasificar los ingredientes y listas ordenadas (`<ol>`) para los pasos cronológicos de la instrucción.
- **Soporte Multimedia:** Inclusión de imágenes descriptivas con su respectivo atributo `alt` para mejorar la accesibilidad.
